# 麦麦低价雷达设计

用户已于 2026-10-14 明确选择“任何餐品的最低实付，咖啡或小食也可以”，并授权建立个人公开仓库、开发项目、提交报名。未来希望作为公众号粉丝福利。以下设计执行此前确认的范围；默认本会话直接实施。

## 产品目标

回答“附近现在什么最便宜，以及怎么拿到这个价格”。用户无需先指定餐品。推荐说明餐品、门店、距离、券/套餐来源、真实实付、时间、操作步骤。免费餐品也进入排序。

## 范围与架构

Node.js >=22.9，零运行依赖。标准 HTTP 服务提供手机友好 H5；CLI 支持演示、真实只读探测、用户主动报价扫描及当次确认后的免费领券。Agent Skill 可直接编排官方客户端工具。官方 Streamable HTTP MCP 客户端通过 initialize/tools/list 实际发现 schema，禁止凭空假设参数或券叠加。

扫描用户指定地址附近可用门店，优先到店自取。按门店查询菜单、门店可用券；候选包括可售单品/套餐和券携带商品码。每个候选都经 calculate-price 真实验证。搜索预算上限和门店数量明确显示，不宣称全渠道/全菜单的全局最低。活动日历作为线索展示，不从营销文案推算价格。报价不可共享到另一账号/门店。

第一版默认只读；领券需当次点击确认或 CLI --confirm，公开接口是一键领取，不承诺限量秒杀。优惠变化检查必须由用户手动触发；没有自动轮询、定时领券或无人值守操作。创建订单、积分扣除、购买会员卡均不包含在本版本。

## 信任与公众号使用

规则核对后的执行修订：官方服务规则禁止凭证托管到未经认证的平台，并限制脚本自动化调用。因此公网生产部署只提供演示，后端拒绝接收个人 Token；真实连接仅限本人本机 loopback 主机及 loopback 请求。后续公众号实时服务须先获得官方授权并明确工具调用适用边界。每个人自行申请、使用本人的 Token；不能共享运营者 Token。个人本机网页 Token 在内存随机会话中最多保留 30 分钟，HttpOnly/SameSite cookie，断开/超时删除，无持久化和账号缓存。生产演示需 HTTPS 与明确的 APP_ORIGIN；同源检查、请求体限制、频率限制及固定静态路径。Token 不出现在 URL、日志、HTML、本地存储、Git 或分享文本中。运行环境的 Token 仅 CLI 使用，不作为网页默认账号。

演示为自造测试数据，显著标明“演示数据，不代表实时优惠”。没有凭证时真实模式不伪装成演示结果。公开参赛声明原样复制官方文件。

## 价格有效性

所有现金按整数分计算；金额缺失、负数、无商品返回、商品不匹配、失效券、非食品（卡/餐具/袋子）、零价但无免费券证据均不进入推荐。0 元报价必须有有效免费券且官方回传对应商品，避免参数错误假免费。优先实付，平价优先更近；距离未知不记为 0。配送价必须明确实际门店和地址上下文；本版默认到店，以免提供不完整外送价格。

## 验收

真实 MCP 传输（JSON/SSE/session/schema）、空及失败价格、跨店排序、券专用商品码、领券显式确认、两个账号隔离、同源与令牌保密有行为测试。桌面/手机检查 H5。完成官方必需文件，验证仓库公开且无秘密。报名简介如实区分已验证与待验证，不编造 WorkBuddy 开发经历。
